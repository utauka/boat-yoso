# 六場ボート予想帳（本格版）

下関・大村・徳山・福岡・住之江・戸田の6場について、次の3つを毎日自動で更新するサイトです。

1. **出目履歴**：直近2年の3連単を「本命（20倍以下）・中穴（21〜60倍）・大穴（61倍以上）」に分けて集計
2. **選手検索**：4桁の登録番号で、勝率・コース別成績・6場での成績・直近10走を表示
3. **今日の買いレース**：戸田・徳山・大村で、インが1着の3連単2点（1レース200円）。本命2点／本命1＋中穴1／中穴2点を画面で切り替え。展示が出てから、イン逃げ率60%以上なら「買い」。登録番号でしぼりこみも可

費用は0円です（GitHubの無料の仕組みだけで動きます）。

## 動かし方（はじめの1回だけ・約20分）

### 1. GitHubのアカウントを作る
https://github.com で無料登録します。すでに持っていれば飛ばしてください。

### 2. 置き場所（リポジトリ）を作る
1. 右上の「＋」→「New repository」
2. Repository name に `boat-yoso` など好きな名前を入れる
3. **Public（公開）を選ぶ**
   - Public なら自動実行が無料・無制限です。Private だと無料枠（月2,000分）を10日ほどで使い切ります。
   - Public でも、サイトは検索エンジンに出ない設定にしてあります。ただしURLを知っている人は見られます。
4. 「Create repository」

### 3. ファイルを入れる
いちばん確実なのは **GitHub Desktop**（無料アプリ）です。
1. https://desktop.github.com を入れて、GitHubアカウントでログイン
2. 「File」→「Clone repository」で、さっき作ったリポジトリをパソコンにコピー
3. このZIPを解凍して、**中身をすべて**そのフォルダに入れる
   - `.github` という見えにくいフォルダも必ず入れてください（Macは Finder で `⌘ + Shift + .` を押すと見えます）
4. GitHub Desktop の左下に「最初のアップロード」などと書いて「Commit to main」→ 上の「Push origin」

### 4. 自動実行とサイト公開を許可する
リポジトリの「Settings」で2か所だけ変えます。
- 「Actions」→「General」→ 一番下の **Workflow permissions** を「Read and write permissions」にして Save
- 「Pages」→ **Source** を「GitHub Actions」にする

### 5. 最初の更新を手で動かす
1. 上の「Actions」タブ → 左の「daily-update」→ 右の「Run workflow」→ 緑のボタン
2. 3〜5分で緑のチェックがつきます。中の「deploy」に出る `https://（あなたの名前）.github.io/boat-yoso/` がサイトのURLです
3. スマホのホーム画面に追加しておくと、アプリのように使えます

あとは何もしなくても、次のとおり自動で動きます。

| いつ（日本時間） | 何をするか |
|---|---|
| 毎日 8:00〜22:50 の10分ごと | 出走表・展示を取りこんで予想を更新。締切25分前からは公式の実オッズで買い目を選び直す |
| 毎日 23:40 | その日の結果を取りこみ、出目履歴・選手データ・予想の答え合わせを更新 |
| 毎週日曜 4:00 | AIを最新のデータで学習し直す |

GitHubの混雑で、実行が数分〜十数分遅れることがあります。

## 予想のしくみ（戸田・徳山・大村／イン逃げの2点買い・1レース200円）

1. **着順AI**（LightGBM）が、各艇の「1着」「2着以内」「3着以内」の確率を出し、3連単120通りそれぞれの「当たる確率」に広げます。インの艇が1着になる確率が**イン逃げ率**です。
   材料は、コース別成績、勝率・級別、モーター・ボート、平均ST、決まり手の傾向（逃げ率・まくられ率など）、風向・風速・波高、場の傾向、そして展示（展示タイムの順位・偏差・ふだんとの差、展示ST、進入、チルト）です。
2. 買い目はすべて**インが1着**の3連単です。本命＝5〜20倍、中穴＝21〜60倍で、それぞれ当たる確率が高い順に2点ずつ候補にします。
3. 配分は画面のボタンで選びます（どれも100円×2点＝200円）：**本命2点／本命1＋中穴1／中穴2点**。
4. **展示が出てから判断**し、イン逃げ率が**60%以上なら「買い」**、それ以外は見送りです。展示前は「展示待ち」と表示します。
5. 締切25分前からは公式の実オッズで本命・中穴を決め直します。

### 過去6か月での成績（学習に使っていない 2026-04-19〜2026-10-18、3場・展示データあり、買いレースは1日約11R）

| 配分 | 的中率 | 回収率 | 当たった時の平均払戻 |
|---|---|---|---|
| 本命2点 | 21.9% | 89.4% | 817円 |
| 本命1＋中穴1 | 14.4% | 76.0% | 1,051円 |
| 中穴2点 | 5.1% | 72.6% | 2,823円 |

買いレースでインが1着になったのは70.1%（見送りを含む全体では56.6%）。回収率は半年で±10%ほどぶれます。

舟券は売上の25%が先に引かれるため、回収率100%を続けて超えるのはとても難しい仕組みです。予想は判断の材料として使い、使う金額の上限を先に決めておいてください。舟券を買えるのは20歳からです。

### 選び方を変えたいとき
`scripts/strategy.py` の数字を書きかえます（GitHubの画面上で鉛筆マークから直せます）。

- `TARGET_STADIUMS` … 予想する場
- `IN_MIN = 0.60` … 「買い」にするイン逃げ率
- `HONMEI_MIN = 5.0` / `HONMEI_MAX = 20.0` / `CHUANA_MAX = 60.0` … 本命・中穴のオッズの範囲
- `DEFAULT_MIX = "2-0"` … 画面の初期の配分（"2-0"＝本命2点、"1-1"＝本命1＋中穴1、"0-2"＝中穴2点）

## データの出どころと注意

- 出走表・直前情報・結果：非公式の **Boatrace Open API**（https://github.com/boatraceopenapi ・MITライセンス）。公式とは関係がなく、欠けや誤りがありえます。
- 締切前のオッズ：ボートレース公式サイトのオッズページから、締切が近いレースだけを3秒以上あけて取得します。取得したオッズはサイトにもリポジトリにも載せず、GitHubの一時保管にだけ置きます。
  - オッズページの読み取り部分は、公式ページの作りに合わせて書いてありますが、作成した環境からは公式サイトに接続できなかったため、実際のページでは未確認です。動かない場合は推定オッズで予想が続きます（画面に「推定」と出ます）。
- 公式サイトの規約では、私的な使用をこえる無断利用や大量アクセスが禁止されています。広く公開したり、広告や有料化をするときは、先に BOATRACE振興会 に確認してください。
